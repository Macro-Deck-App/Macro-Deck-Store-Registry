First release for Macro Deck 3.

- One pack replaces the separate Powered Steel category packs from Macro Deck 2.
- 1,852 icons: all of Font Awesome Free 6.2.0, including brand icons such as Discord, Twitch and Spotify.
- Every icon comes in three looks: Active (gold stripes, the default), Inactive (grey stripes) and Clear (see-through stripes in the button's background colour).
- Pick a look in the button editor under Icon appearance, or switch looks with the Set Icon Appearance action, for example to show a toggle's on and off state.

Icons already on your Macro Deck 2 buttons are carried over when Macro Deck 3 migrates your setup.
