First release of the VS Code Plugin for Macro Deck and its companion VS Code extension, **Macro Deck Bridge**.

- **Run VS Code commands and tasks from your deck.** Any command, including other extensions' commands, with optional arguments, and any workspace task.
- **See VS Code on your buttons.** Active file, language, workspace, Git branch, error and warning counts, unsaved files, and debugging state are available as variables.
- **React to VS Code.** Events fire when a file is saved, a debug session starts or stops, or a task finishes.
- **Choose which window a button controls.** Pin a window, bind a button to a project, or send it to all windows. VS Code's status bar shows which window is controlled.
- **Simple, local pairing.** Copy a token from VS Code and paste it into the plugin's setup. Everything stays on your computer.

Install the VS Code extension from the `.vsix` attached below, or from the VS Code Marketplace once it is listed there.
