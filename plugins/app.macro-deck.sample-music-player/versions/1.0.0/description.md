# Sample Music Player

Sample Music Player is a synthetic music service for exploring and testing Macro Deck's complete
music-player integration without connecting a real account.

## Features

- Playback controls including play, pause, seek, volume and track navigation
- A browsable sample catalogue with artwork
- Output-device selection and playback transfer
- Two player instances with different capabilities
- Example actions, variables and track-change events backed by the same playback state

## Setup

Install the plugin, then add the **Sample library** instance to a Music Player widget. No account,
credentials or external service are required.

Version 1.0.0 supports Macro Deck on macOS with Apple Silicon (`osx-arm64`).

Source code, development instructions and automated tests are available in the
[Macro Deck Sample Plugins repository](https://github.com/Macro-Deck-App/Macro-Deck-Sample-Plugins).
