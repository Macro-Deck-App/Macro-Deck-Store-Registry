This release includes some bug fixes, rating stars variable, and a queue item action. The SDK has been updated to 3.0.1. A new icon was also created for this release. 

## Additions
- Added Queue Item Action: Add the selected song to the Play Queue, at the specified position
- Added a rating starts variable: Display the rating as stars ★ (`\u2605`). So a rating of 4 would show as ★★★★
- New Plugin Icon

## Fixes
- Fixed a possible issue where the Play Item action would not show for some users

## Changes
- Improved Actions Logic
- Improved HTTP Error Handling
- Updated to SDK 3.0.1
- Changed name to `BeefWeb Plugin`
