## Initial Release

- A hotkey-pressed trigger that fires for any modifier+key combination pressed anywhere on the machine, even while another app has focus
- An optional toggle to also stop that key from reaching whatever app is focused
- Device, Profile and Folder scoping, so the same combo bound in every folder reacts only where it's actually open
- No setup required - every setting lives directly on the trigger, nothing to configure first

**Full Changelog**: https://github.com/PyFlat/System-Hotkeys/commits/v1.0.0
