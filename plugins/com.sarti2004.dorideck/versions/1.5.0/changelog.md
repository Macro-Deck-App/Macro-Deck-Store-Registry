## What's new

### Switch folders by Dorico/Cubase window
New Event: **Dorico/Cubase window focused**. Use it as a button trigger to switch folder or profile when a Dorico, Cubase or Nuendo secondary window comes to the front. For example, set **Window title** to *starts with* `Mixer` to switch to the "Mixer" folder. 

### Convert PDF to MusicXML
New action: **Convert PDF to MusicXML**. It converts new PDFs in a working folder to `.mxl` files next to them using [Audiveris](https://audiveris.github.io) (which needs to be installed on your computer).
