## Tile actions and wall configuration

- With movement arrows off and **Press script** on None, a camera tile declares no controls, so its Short Press and Long Press actions run again. The tile no longer opens the camera window instead of running the action.
- The camera wall configuration now uses the configuration form root, so the Camera 1-4 pickers, columns, fit and arrow settings render correctly.
- README and Store copy describe both ways to run actions: without arrows, or with a press script.
