First release in the Macro Deck Store.

- Two widgets: a read-only list of your open Vikunja tasks, and a checklist where pressing a task marks it as done.
- Priority dot, due date and swipe paging on list tiles, plus a counter option for square tiles.
- Settings for text size, card size and what square tiles show.
- Setup checks that the address answers like Vikunja before the token is saved.

Requires Vikunja 0.24.0 or newer and an API token. Windows x64 only.
