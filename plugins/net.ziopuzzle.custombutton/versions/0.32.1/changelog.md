## Custom Button 0.32.1

Create custom Macro Deck widgets using XML or a native block editor. Combine text, shapes, graphs, images, conditional styles and animations, with multiple interactive press targets and sliders in a single widget.

- Includes basic drawing templates and advanced clock, meter, history graph and music-player layouts.
- Connect Macro Deck variables through configured actions and display activation/update events.

Requires Macro Deck 3.0.0-beta.14 or later. Packages include the .NET and ASP.NET Core runtimes and dependency license notices; no separate .NET installation is required.

### Known limitations

- Macro Deck internal images (media artwork and installed icon pack images) may fail to load. The cause is unverified and is not fixed by this release.
- After copying a widget, retarget or recreate its event flows.
- Windows x64 has been tested locally. macOS/Linux execution has not been verified on devices.
