Store review fixes, new lighting options and a new name: Razer App Controller (unofficial).

- Synapse is never restarted automatically. Settings has a "Restart Synapse when I save" switch instead.
- The plugin does not use Synapse's debug port until you turn on Synapse control in the settings.
- Clearer security warning, and an exact description of the change to Synapse's startup entry.
- New: Chroma lighting (no setup needed) with static colour, breathing, spectrum cycling and wave, with brightness and speed.
- New: Synapse lighting effect settings (second colour, random, duration, wave direction) and a Synapse brightness action.
- New variables: razer_keyboard_brightness and razer_mouse_brightness.
- New icon.
