# Macro Deck Store Registry

The official registry for packages published in the Macro Deck Store.

This registry is managed automatically. Do not manually add, modify, or remove package data.
Packages cannot be submitted through pull requests.

Package submissions will be handled through the **Macro Deck Creator Portal** *(coming soon)*.

Problems with packages or plugins must be reported through the Macro Deck Store or in the respective
package repository, not in this registry.

- [Macro Deck on GitHub](https://github.com/Macro-Deck-App/Macro-Deck)
- [Macro Deck website](https://macro-deck.app)
